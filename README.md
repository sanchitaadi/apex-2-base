# Apex 2.0

Premium Apex Public School website foundation.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Supabase

Copy `.env.local.example` to `.env.local` and add your Supabase project URL and anon key.

Next steps:
1. Connect Supabase database.
2. Add authentication.
3. Build the admin CMS.
4. Connect all public content to the database.
